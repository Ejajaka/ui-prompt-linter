# Store privacy / permission answers

Use these answers in the "Privacy" tab of the Chrome Web Store dashboard (and the
"Privacy" section of the Microsoft Edge Partner Center).

## Single purpose

Review natural-language UI prompts for missing labels, colours, placement and
actions before they are sent to a UI generator, and produce a validated rewrite.

## Permission justification

The extension declares **no permissions** - no storage, no host access, no
clipboard permission. Everything runs locally inside the popup. (If the store
asks about clipboard use, note that the popup only writes to the clipboard on an
explicit "Copy prompt" click via the standard Clipboard API.)

## Remote code

- **No, I am not using remote code.** All code is bundled in the extension.

## Data usage

- The extension collects **no user data**. Leave all "collect" boxes unchecked.
- It does not use analytics, and transmits nothing over the network.
