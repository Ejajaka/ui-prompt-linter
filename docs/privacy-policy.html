Vector
UI/UX Prompt Review

Privacy Policy

Last updated: November 14, 2026

Vector is a UI prompt review tool available as a web app, a browser extension and a native Android app. It reviews natural-language UI prompts for missing details before they are sent to a UI generator.

Data collection

Vector collects no data. It does not:

  • collect, store or transmit any prompt text, browsing history, or personal information;
  • use analytics, trackers, or cookies;
  • require an account or sign-in.

Your prompt history and preferences are stored only in your device's local storage (or the app's local database on Android). You can clear them at any time in Settings.

How it works

The deterministic Rules engine runs entirely on your device — in the browser via Pyodide, in the extension popup, and on-device in the Android app. The optional BERT engine loads a quantized DistilBERT model in your browser and also runs locally. Neither uploads your prompt.

The optional LLM engine only runs if you add an OpenAI-compatible endpoint and API key in Settings. When you use it, your prompt is sent to that endpoint and to no other third party.

Floating assistant

On ChatGPT, Claude and Gemini the extension adds a small floating PL button. It reads the text currently in the chat composer only when you click that button, analyses it locally with the same offline rules engine, and never transmits it to Vector or any third party. Closing the panel discards it.

Clipboard

The web app and extension write to the clipboard only when you explicitly click “Copy prompt”, using the standard Clipboard API on that click.

Third parties

No data is shared with any third party. The only exception is the LLM endpoint you choose to configure yourself in Settings.

Contact

For questions or issues, open an issue on the project repository: github.com/Ejajaka/ui-prompt-linter.

This policy applies to the Vector web app, browser extension and Android app. It does not cover the separate Streamlit full engine, which runs BERT and LLM features server-side.
