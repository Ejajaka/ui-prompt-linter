Prompt Linter
UI/UX Prompt Review

Privacy Policy

Last updated: November 11, 2026

Prompt Linter is a browser extension that reviews natural-language UI prompts for missing details before they are sent to a UI generator.

Data collection

Prompt Linter collects no data. It does not:

  • collect, store or transmit any prompt text, browsing history, or personal information;
  • use analytics, trackers, or cookies;
  • require an account or sign-in.

How it works

All analysis runs locally in your browser using a deterministic rule engine. Your prompt never leaves your device. The extension requests no special permissions.

Clipboard

The popup writes to the clipboard only when you explicitly click “Copy prompt”, using the standard Clipboard API on that click.

Third parties

No data is shared with any third party.

Contact

For questions or issues, open an issue on the project repository: github.com/Ejajaka/ui-prompt-linter.

This policy applies to the Prompt Linter browser extension and the Prompt Linter website.
